# Member 2: Bedaya Design And Prototype

## Run

Open `bedaya-prototype/index.html` locally in a browser. No build or installation is needed. Arabic and English, owner/partner/admin roles, and responsive mobile layouts are included.

## Deliverables

- `bedaya-prototype/`: source code, supplied logo, bundled font and icons, and offline clickable prototype.
- `bedaya-prototype/HANDOFF.md`: detailed implementation notes, demo script, QA scope, and open items.
- `bedaya-prototype/editable-screens/`: 132 editable SVG exports covering 33 screens in both languages at desktop/mobile widths.
- `bedaya-prototype/bilingual-strings.*`: shared bilingual copy.
- `bedaya-prototype/screen-inventory.csv`: screen-to-feature mapping.
- `bedaya-prototype/qa-*.json` and `qa-*.csv`: executed QA results.
- `bedaya-prototype/qa/`: screenshot evidence.
- `bedaya-prototype/backup-demo.webm`: bilingual owner/partner/admin walkthrough.
- `bedaya-prototype/figma-repair/`: unexecuted recovery plugin for the existing Figma draft.
- `planning/`: earlier planning PDF and initial copy/checklist drafts. Use the prototype's current copy and QA results for integration.

The English Bedaya name is centred below the Arabic logo in a smaller font.

## Integration Status

This is a design/reference prototype, not a production application. Identity, OCR, signatures, banking, notifications, assistant responses, regulatory data, and analytics are mocked or illustrative. Do not treat them as live integrations or verified Jordanian rules.

The reviewed deliverables are the offline prototype and SVG exports. The [Figma draft](https://www.figma.com/design/tQdvrFCJxgSi9H7tsHu1Km) still requires layout repair and visual verification because the connector usage limit prevented the final repair.

Browser QA used Chromium viewport simulation, not physical devices or Safari. Integrated-app testing remains deferred until the team application exists.

Generated duplicate QA recording fragments and the redundant ZIP distribution archive are not tracked; their final deliverables are included as individual files.
